# Nebiyu Tefera — Personal Website

This repository contains the source code for my personal website, developed to showcase my academic background, research interests, professional experience, and technical projects.  
The site serves as an online portfolio and a central hub for my journey in Computer Science, AI, and postgraduate studies.

---

## 🌐 Live Website

Visit the website here: *(nebiyutefera.tech)*

---

## 🎯 Purpose

- Present my academic and research profile  
- Highlight projects, publications, and technical experience  
- Share personal achievements, leadership roles, and certifications  
- Provide an easy way for universities, professors, and collaborators to learn more about my work  

---

## 🛠️ Technologies Used

- **Frontend:**  React, and Tailwind 
- **Build/Deployment:** on .tech  

---

## 📂 Features

- Responsive modern UI  
- Research-focused profile sections  
- Portfolio of projects  
- Contact page  
- Optimized for admissions committees and professional reviewers
